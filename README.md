# Block Character Animation Demo

Godot 4 demo displaying three beginner-style block characters simultaneously:

- Idle
- Walk
- Punch

The model was created in Blender and uses the Mixamo-compatible bone map plus Melee and Shooter animation libraries from [Godot4-OpenAnimationLibraries](https://github.com/catprisbrey/Godot4-OpenAnimationLibraries).

## Play online

[Open the Web demo](https://ouaneng.github.io/3D/)

## Open in Godot

Import `project.godot` using Godot 4. The main scene is `main.tscn`.

Thai instructions are available in [README_TH.md](README_TH.md).
